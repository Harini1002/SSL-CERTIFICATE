# 📘 CertGuard AI — Technical & Architectural Documentation

This document provides a comprehensive technical overview of the CertGuard AI platform. It serves as an engineering manual, detailing the application architecture, database schemas, REST APIs, Model Context Protocol (MCP) server tools, AI prompt setups, and mailing subsystem integrations.

---

## 🗺️ 1. High-Level Architecture

```mermaid
graph TD
    A[React 19 SPA Frontend] -->|REST & JSON-RPC| B[Express.js Node.js Server]
    B -->|Local Read/Write| C[(data/certguard.json DB)]
    B -->|Child Process Exec| D[Python 3 Mailer Script]
    B -->|Socket Connection| E[Public Internet Port 443]
    B -->|REST HTTPS| F[Google Gemini API]
    D -->|Secure SMTP| G[SMTP Gateway (Gmail / smtp.gmail.com)]
```

The system is split into three main layers:
1.  **Presentation Layer**: Responsive React dashboard built with Tailwind CSS, supporting interactive telemetry clocks, live CLI-style check consoles, data visualization (security grade counters), AI report previews, and chat interfaces.
2.  **Application Layer**: Express.js server providing routing, file database logging, exporting format compilers, dynamic Vite dev server mounting, and Model Context Protocol schema endpoints.
3.  **Utility Layer**: Dedicated module structures executing raw TCP client socket checks for TLS payloads and spawning Python subprocess engines for TLS SMTP email dispatches.

## 🗄️ 2. Database Schema (`data/certguard.json`)

The platform utilizes a flat-file JSON database for fast transactional reads and writes, tracking history up to 500 scans, 100 incident tickets, and 200 mail logs.

```typescript
interface DatabaseSchema {
  scans: ScanResult[];
  sessions: DashboardSession[];
  tickets: IncidentTicket[];
  mails: MailAlert[];
  users: UserAccount[];
}
```

### Type Definitions (`src/types.ts`)

#### `ScanResult`
Represents the cryptographic status and scan metadata of an X.509 certificate.
```typescript
export interface ScanResult {
  domain: string;
  issuer: string;
  expiryDate: string;
  validFrom: string;
  daysRemaining: number | null;
  protocol: string;
  serialNumber: string;
  version: string;
  sanList: string[];
  signatureAlgorithm: string;
  scanTimestamp: string;
  status: "success" | "error";
  riskLevel: "expired" | "critical" | "high" | "medium" | "low";
  sslGrade: "A" | "B" | "C" | "D" | "F";
}
```

#### `IncidentTicket`
ITIL-compliant ticket configuration generated by Gemini AI reasoning models.
```typescript
export interface IncidentTicket {
  ticketSubject: string;
  ticketBody: string;
  urgencyLabel: "P1" | "P2" | "P3" | "P4";
  remediationSteps: string[];
  prediction: string;
  createdAt?: string;
  domain?: string;
}
```

#### `MailAlert`
Tracks outbound alert notifications triggered manually or automatically by the server.
```typescript
export interface MailAlert {
  id: string;
  domain: string;
  sender: string;
  recipient: string;
  subject: string;
  body: string;
  status: "dispatched" | "failed";
  sentAt: string;
}
```

## 🔌 3. REST API Reference

All requests and responses use JSON format. 

### 📡 Scans & Statistics

#### 1. Fetch History
*   **Endpoint**: `GET /api/history`
*   **Description**: Returns all historical records, sessions, active user credentials, mail dispatches, and dashboard aggregates.
*   **Response**:
    ```json
    {
      "scans": [...],
      "sessions": [...],
      "tickets": [...],
      "mails": [...],
      "users": [...],
      "stats": {
        "totalScans": 15,
        "totalSessions": 2,
        "totalTickets": 4,
        "totalMails": 3,
        "oldestScan": "2026-06-09T09:58:12Z"
      }
    }
    ```

#### 2. Execute Batch Scan
*   **Endpoint**: `POST /api/scan`
*   **Payload**:
    ```json
    {
      "domains": ["google.com", "expired.badssl.com"]
    }
    ```
*   **Description**: Triggers a live TCP handshake scan on each domain, registers the findings, aggregates risk statistics, and triggers automatic SMTP warnings if critical certificate vulnerabilities are encountered.
*   **Response**:
    ```json
    {
      "success": true,
      "results": [...],
      "summary": {
        "total": 2,
        "expired": 1,
        "critical": 0,
        "high": 0,
        "medium": 0,
        "low": 1,
        "securityScore": 50
      },
      "session": { "id": "sess-12345", "securityScore": 50 },
      "bulkMailDispatched": { "sent": true, "domains_alerted": [...] }
    }
    ```

### 🧠 Gemini AI Automation Endpoints

All AI automation runs using the `@google/genai` library targeting the `gemini-3.5-flash` model.

#### 1. Pre-Auth Exposure Diagnostics
*   **Endpoint**: `POST /api/auth/ai-leak-scan`
*   **Payload**:
    ```json
    {
      "username": "operator_name",
      "email": "corporate_email@company.com"
    }
    ```
*   **Description**: Evaluates operator identity against simulated credential exposure logs, returning threat indicators and credentials recovery runbooks.

#### 2. Draft ITIL Incident Ticket
*   **Endpoint**: `POST /api/ticket`
*   **Payload**:
    ```json
    {
      "result": { "domain": "expired.badssl.com", ... }
    }
    ```
*   **Description**: Compiles SSL certificate failure details into structured JSON compliance tickets.

#### 3. Compile Advisory Email
*   **Endpoint**: `POST /api/email`
*   **Payload**:
    ```json
    {
      "result": { "domain": "domain.com", "daysRemaining": 12, ... }
    }
    ```
*   **Description**: Drafts context-aware renewal reminders featuring step-by-step remediation plans.

#### 4. Portfolio Executive Summary
*   **Endpoint**: `POST /api/summary`
*   **Payload**:
    ```json
    {
      "results": [...],
      "summaryStats": { ... }
    }
    ```
*   **Description**: Synthesizes global vulnerabilities into CISO executive reports.

#### 5. DevSecOps Chat Buddy
*   **Endpoint**: `POST /api/chat`
*   **Payload**:
    ```json
    {
      "messages": [{ "role": "user", "content": "How do I fix a sha1Signature?" }],
      "results": [...]
    }
    ```
*   **Description**: Multi-turn conversational chat with complete context of the scanned domain portfolio.

## 🛠️ 4. Model Context Protocol (MCP) Server

CertGuard AI embeds an MCP Server compliant with AI Agent Tool Calling. Developers and external LLM frameworks can query and run tasks programmatically.

### Registered Tools Schema

| Tool Name | Input Arguments | Description |
| :--- | :--- | :--- |
| `check_ssl_cert` | `{ "hostname": string }` | Perform socket handshake on the target host, returning X.509 parameters. |
| `draft_escalation_ticket` | `{ "domain": string }` | Probe endpoint and generate an ITIL incident ticket using Gemini. |
| `dispatch_renewal_alert_email` | `{ "domain": string, "recipient": string }` | Draft renewal advisory and route email using configured SMTP options. |
| `fetch_ist_time` | None | Returns precise local system clock configured to Indian Standard Time. |

*   **Tools Schema Discovery**: `GET /api/mcp/tools`
*   **Tool Execution Router**: `POST /api/mcp/execute`
    *   Payload: `{ "tool": "check_ssl_cert", "arguments": { "hostname": "google.com" } }`

## 📬 5. Python Mailing Subprocess Bridge (`mailer.py`)

Node.js executes SMTP routing by spawning a Python child process. This ensures SMTP configuration handles custom SMTP, ports (465 for SSL/TLS, 587 for STARTTLS), and authentications natively via Python's standard `smtplib` library.

### Process Invocation Signature
```bash
python3 mailer.py --action [test|critical|renewal|bulk] --data [JSON_PAYLOAD_STRING] --ai-content [AI_ADVISORY_TEXT]
```

### JSON Outputs Parsed by Node
```json
{
  "sent": true,
  "connected": true,
  "message": "Mail successfully dispatched to smtp.gmail.com"
}
```

## 📂 6. Exporters Formatting

*   **CSV Exporter (`/api/export` with `format=csv`)**: Outputs standard cert logs (Domain, Issuer, Expiry, Days Left, Protocol, Grade).
*   **User Ranked CSV (`/api/export` with `format=user_csv`)**: Sorts domains by urgent days-to-expire, including warning tags (e.g. `EXPIRED`, `IMMINENT_OUTAGE`).
*   **Renewal Tasks Markdown (`/api/export` with `format=user_md`)**: Generates structured, readable checklist sheets with priority icons indicating which certificates need immediate CA re-issue.
